# 2-minute demo video script (English)

Record at 1440×900, three laptops (or three browser profiles). Presenter = main screen.

| Time | Screen | Voice-over |
| --- | --- | --- |
| 0:00–0:12 | Landing → Start a room | "Teams write specs with AI now, but everyone has a private chat. Relay gives the team one shared agent." |
| 0:12–0:35 | Jieun's laptop sends "Remove typing from the invite step…"; presenter's document changes live; click Jieun's name tag → why + her conversation | "Jieun asks the agent in her own session. My document changes in place, and I can see who changed it, why, and the conversation behind it." |
| 0:35–1:05 | Presenter sends "Switch the team invite in section 3 to manual invites." → reply with *Opinions differ* | "I want the opposite. The agent applies my request, but it remembers Jieun changed this 5 minutes ago for a different reason, so it flags the conflict and opens a discussion." |
| 1:05–1:30 | Discussions tab: three options, Minsu and Jieun voted; presenter votes → Conclude → section 3 and Decision log update | "The team votes. Once we conclude, the agent writes the result into the body and the decision log." |
| 1:30–1:45 | Minsu edits section 1 directly; presenter sees "Minsu editing" then the change | "People can still edit directly. Everyone sees it live, and it is logged like any agent edit." |
| 1:45–2:00 | Activity tab with diffs → invite link / URL on screen | "One agent, used by the whole team. Every change shows who made it and why. Try it yourself at …" |

Backup: if the network is slow, record each step separately and cut; keep the agent's real response time visible at least once.
